## Sobre mim

Desenvolvo **sites, sistemas e automações** que resolvem problemas reais de negócio. Atuo como freelancer, entregando soluções completas para empresas e agências: da landing page de alta conversão à automação de atendimento com inteligência artificial.

Minha base vem da **análise de sistemas e dados**, o que me faz olhar para cada projeto pensando em processo, eficiência e resultado, não só em código.

## O que eu faço

- 🌐 **Desenvolvimento Web:** sites e aplicações modernas, rápidas e responsivas com Next.js, React e TypeScript
- 🤖 **Automação & IA:** agentes de IA, fluxos automatizados e integrações entre sistemas (n8n, APIs, WhatsApp)
- ⚙️ **Back-end & APIs:** APIs REST com Node.js/Express e Java, integração com bancos SQL e NoSQL
- 📊 **Análise de Sistemas e Dados:** levantamento de requisitos, modelagem de dados e consultas SQL
- 🚀 **Deploy & Infra:** publicação e manutenção de projetos na Vercel, versionamento com Git/GitHub
